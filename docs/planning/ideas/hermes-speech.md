### Hermes Speech (https://hermes-agent.nousresearch.com/marketplace/hermes-speech, source https://github.com/allmodels-io/hermes-speech)
**Verdict:** Skip — Studio already has TTS and STT with many providers (including a custom OpenAI-compatible one); this plugin only adds one paid middleman (AllModels).
**What it is:** A Hermes Agent plugin (v0.3.3, needs Hermes >= 0.20.0) that registers TTS and STT providers backed by AllModels, a paid single-API-key router for 80+ speech models (ElevenLabs, Cartesia, Fish Audio, Soniox, OpenAI-compatible). It has two tools (`allmodels_speech_setup`, `allmodels_speech_manage`) and a slash command for signup, voice search, speed, balance and test audio. Defaults: Fish s2-1-pro (TTS), Soniox async v5 (STT).
**Already in Studio/Hermes?** Yes. Studio has its own voice stack in `packages/server/src/modules/studio/services/voice/` (tts + stt, routes `routes/tts.ts` and `routes/stt.ts`, settings stores, local STT model manager, a voice proxy and `config-sync.ts` that writes the stt/tts sections of Hermes config.yaml). TTS providers: custom, deepinfra, doubao, edge, elevenlabs, gemini, mimo, minimax, mistral, openai, xai. STT: openai-compatible, doubao, local model, hermes-cloud. The "custom" provider can already point at AllModels' OpenAI-compatible API.
**How to use it in Hermes Studio:** Not needed. If someone wants AllModels anyway: add it as a "custom" OpenAI-compatible TTS/STT provider in Studio voice settings (base URL from their docs, key in settings). Installing the plugin with `hermes plugins install allmodels-io/hermes-speech --enable` would fight with config-sync, which owns the tts/stt config sections.
**How to use it in herdr:** Not relevant. herdr is a terminal multiplexer; it has no voice features and the plugin is a Hermes plugin only.
**How to integrate it properly (build work):**
- Nothing required. Optional, small: a "AllModels" preset in the custom TTS/STT provider form (prefilled base URL and model names), in the Studio voice settings page.
- Optional idea worth copying (small): voice search/preview in Studio TTS settings (filter by language, gender, provider and play a sample).
**Risks:** Sends all spoken text and audio to a third party (api.allmodels.io), a paid service with prepaid balance; agent-driven signup creates an account and stores `ALLMODELS_API_KEY` in Hermes env. Plugin config clashes with Studio's config-sync. Small vendor, young project (added ~2 months ago).
**Facts:** MIT licence (plugin.yaml and LICENSE; the marketplace page itself does not state it). Python, ~6k lines incl. tests, uses bundled `openai` and `httpx`. Last commit 2026-09-28; v0.3.3.
