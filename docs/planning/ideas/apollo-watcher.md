### Apollo Watcher (https://watcher.apolloresearch.ai/)
**Verdict:** Skip — it is a closed, company-sold product that only supports Claude Code and Codex, and Studio already has approvals; at most watch it for later.
**What it is:** A runtime monitor from Apollo Research. It checks each agent action before it runs, blocks risky ones with a reason, keeps an audit trail, lists which agents/skills/plugins are in use, and sends findings to Splunk, Datadog, Slack, etc. A client runs on laptops/containers, or it sits behind a model gateway (LiteLLM, Portkey), or you use a Python SDK. It can be self-hosted (AWS/Azure/on-prem container images, your own model keys) or Apollo's hosted cloud (Western Europe).
**Already in Studio/Hermes?** Yes, in part. Studio has approval modes ask / guarded / auto (`coding-agents/services/approval-policy.ts`, `approvals.ts`) that put dangerous actions (rm outside folder, sudo, force push, curl|sh) in front of you. Hermes has its own command approval + allowlist (`tools.approval`, used by `bridge_runtime.py`) and a write gate for memory/skills (`hermes/services/write-gate`). Ekko has approvals too. Clean rooms add a Docker container and an allowlist network proxy. Missing today: an AI judge of intent, a central audit log, and alerts to outside tools.
**How to use it in Hermes Studio:** Not directly. The page says self-serve agents are Claude Code, Codex, Copilot CLI (Hermes not listed; "50+ harnesses" is enterprise only). Only workable path: install its client inside a clean-room image so Claude Code/Codex chats get hooked, pointing `--watcher-api-url` at a self-hosted backend. Needs a sales call; pricing is not public.
**How to use it in herdr:** Not relevant. herdr panes just run the same agents; the client would hook the agent, not herdr.
**How to integrate it properly (build work):**
- Nothing worth building now.
- If tried: add a clean-room image variant with the client installed, plus a setting for the API URL (small).
- Better home-grown option: an audit log of approvals/denials in Studio's Agent work page, and a webhook/Mattermost alert on blocked actions (small-medium).
**Risks:** Closed source / licence not stated (repo `ApolloResearch/watcher-bin` holds install script and SDK only, no releases listed). Install is `curl | bash`. Hosted mode sends session data to a third party. Self-hosting needs cloud infra and an LLM judge (extra token cost). Young repo (8 stars, 31 commits). Hermes agent likely unsupported.
**Facts:** Licence unclear (third-party licences file only); 8 stars, 1 fork, no releases shown, last commit date not visible; client for macOS arm64 and Linux x86_64; Python SDK wheel; Claude Code + Codex supported; pricing by sales call.
